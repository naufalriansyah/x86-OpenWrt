## About This Project
Firmware ini berbasis dari OPENWRT OFFICIAL, dibuat untuk menjadikan sebuah komputer berbasis x86 sebagai perisai utama dalam berinternet dirumah, dilengkapi dengan Adguardhome, bandix monitor, Samba Server, Tinyfilemanager and more
## Feature
- Parental Control by AdguardHome
- Bandwith monitor by bandix
- Trafic monitor by bandix
- sqm cake qos
- etc
